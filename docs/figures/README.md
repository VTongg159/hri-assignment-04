# Ảnh báo cáo

Đặt ảnh chụp Gazebo, RViz và terminal vào thư mục này trước khi biên dịch
`../report.tex`. Có thể đặt ảnh cạnh file `.tex` hoặc trong `docs/images`.

| Tên file trong báo cáo | Nội dung |
| --- | --- |
| `gazebo_turtlebot4.png` | Robot trong Gazebo |
| `rviz_robot_scan.png` | RobotModel và LaserScan |
| `topic_verification.png` | Kiểm tra topic |
| `slam_in_progress.png` | Quá trình mapping |
| `completed_map.png` | Bản đồ sau khảo sát |
| `map_saved.png` | Lưu YAML và PGM |
| `amcl_localization.png` | Localization trên bản đồ |
| `nav2_path_costmap.png` | Global path và costmap |
| `goal_1.png`, `goal_2.png`, `goal_3.png` | Ba goal trên RViz |
| `navigation_result.png` | Kết quả action hoặc log Nav2 |

Nếu ảnh cũ có tên `topic_vertification.png` hoặc `complete_map.png`, đổi thành
`topic_verification.png` và `completed_map.png` để khớp với báo cáo.
`generated_map.png` là ảnh xem trước của map từ lần kiểm tra trước đó, không
thay thế ảnh khảo sát và các ảnh goal của lần nộp bài.
